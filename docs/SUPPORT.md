# Nuvriqo Portal+ — Support Policy

This page is prepared for publication as the customer-facing support policy for the first Marketplace release. Replace the contact placeholders with the final Nuvriqo support URL/email before Marketplace submission.

## Supported platform

Nuvriqo Portal+ supports Jira Service Management Cloud. The V1 release is a Forge app and does not support Jira Server or Data Center.

## Getting support

Customers should contact Nuvriqo support through the support channel published on the Atlassian Marketplace listing.

When reporting a problem, include where possible:

- Atlassian site URL;
- affected JSM project/service desk;
- whether the problem affects administrators, agents or portal-only customers;
- approximate time of the problem;
- screenshot/error message;
- steps to reproduce the problem.

Do not send passwords, API tokens or other credentials to Nuvriqo support.

## Support coverage

Nuvriqo supports:

- installation and configuration questions;
- Portal+ dashboard and customer portal behavior;
- service category/request-type mapping;
- status mapping and dashboard counters;
- request search/filtering and CSV export;
- confirmed defects in supported Portal+ versions;
- Marketplace licensing/subscription questions relating to Portal+.

Issues caused solely by Jira/JSM configuration, Atlassian outages or unsupported Atlassian product behavior may require investigation or escalation to Atlassian.

## Response targets

Initial Marketplace launch targets:

- Critical production issue: target initial response within 1 business day.
- Normal defect/support request: target initial response within 2 business days.
- Feature request/general question: target initial response within 3 business days.

These are response targets rather than guaranteed resolution times. Severity, reproducibility and Atlassian dependencies can affect resolution time.

## Security issues

Potential security vulnerabilities should be reported privately using the security contact published by Nuvriqo. Do not disclose suspected vulnerabilities publicly before coordinated remediation.

## Supported versions

Nuvriqo supports the currently published Marketplace version of Portal+ and will normally ask customers to update to the current version before performing extended defect investigation.
