# Portal+ — Release Notes

## Version 1.0 — first Marketplace release

Marketplace build 4.1.0, September 2026. Jira Service Management Cloud.

### Customer workspace

- A branded dashboard at the top of the JSM portal: counters, Action Centre, services, announcements, useful links and guides.
- My Requests with search, filters, saved views, up to 8 columns (including Description) and live SLA status.
- Request detail with the fields you choose to show, SLA status and a progress timeline.
- Customer reports by period (30 or 90 days, 6 or 12 months, all time): created vs resolved, by type and status, SLA performance and average resolution time.
- CSV and Excel export of the columns shown in My Requests.
- Guides & documents library per experience, linked to your Confluence knowledge base.

### Self-service with control

- Customers can edit the fields you allow (text, multi-line text, number, date, date and time, dropdown), with values checked before saving.
- Optional Close and Escalate actions that move a request only into the statuses you choose.
- An internal, agent-only comment records which customer made each change. You can switch it off.

### Several customers on one project

- Up to 12 experiences per project, each with its own brand name, logo, colours, wording, services and guides.
- Experiences mapped to JSM organisations and to separate JSM help centers on one shared project.
- Optional narrowing by a dropdown custom field, such as Customer.
- White-label option to hide the "Powered by Nuvriqo Portal+" footer.

### Security

- Runs entirely on Atlassian Forge: no Nuvriqo servers and no data sent outside Atlassian.
- Customers see only requests they reported or that are shared with their organisations. This is checked on the server for every read and every change.
- No "Allow access" consent prompt for portal customers.

### Nuvriqo suite

- Approvals and My Assets sections appear automatically when Nuvriqo Smart Approval Manager or Asset Manager is installed.
