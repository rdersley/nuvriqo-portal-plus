# Nuvriqo Portal+ — Marketplace Listing Draft

## App name

**Nuvriqo Portal+ for Jira Service Management**

## Tagline

Turn your Jira Service Management portal into a clearer customer service dashboard.

## Short description

Portal+ adds a configurable service dashboard, customer-friendly quick actions, request search/filtering and CSV export directly inside Jira Service Management while keeping Jira permissions and request forms as the system of record.

## Long description

Nuvriqo Portal+ helps Jira Service Management teams make their customer portal easier to use without replacing Jira or introducing another customer login.

Portal+ enhances the existing JSM portal with a compact service dashboard and configurable navigation. Customers can see useful request counters, find recent requests, search and filter visible requests, launch the right request form from customer-friendly categories and export their own visible request history to CSV.

Administrators configure Portal+ from the JSM project settings area. Portal+ automatically discovers the service desk, request types, customer organizations and workflow statuses so normal setup does not require copying Jira IDs into configuration screens.

### Key capabilities

- Customer service dashboard embedded in the existing JSM portal.
- Open, Awaiting customer and Awaiting support request counters.
- Configurable status mapping for different Jira workflows.
- Customer-friendly service categories and request-type quick actions.
- Request search, status filter, request-type filter and sorting.
- Click-through to existing JSM customer requests.
- CSV export of customer-visible requests.
- Organization-aware configuration foundations.
- Automatic JSM configuration discovery.
- Forge-hosted configuration storage.
- Uses the customer's own Jira/JSM permissions for customer request data.

### Designed for Jira, not around it

Portal+ does not replace JSM authentication, request forms, permissions, workflows or request storage. Jira Service Management remains authoritative. Portal+ provides a clearer customer experience over the service management configuration you already operate.

### Privacy-first architecture

Portal+ is built on Atlassian Forge. The V1 app uses Atlassian-hosted compute and Forge storage and does not use a third-party remote backend or external analytics service. Customer request reads are performed in customer context so Jira/JSM continues to enforce request visibility.

## Suggested Marketplace highlights

1. **A real service dashboard for JSM customers** — put request state, recent activity and quick actions where customers can actually use them.
2. **One JSM project, clearer customer experiences** — organize existing request types into customer-friendly Portal+ categories without rebuilding Jira forms.
3. **Fast to configure** — Portal+ discovers request types, organizations and statuses automatically and keeps Jira permissions authoritative.
