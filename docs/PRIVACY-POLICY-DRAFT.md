# Nuvriqo Portal+ — Privacy Policy Draft

**Publication status: vendor/legal review required before use as the Marketplace privacy-policy URL.**

## Scope

This policy describes the handling of data by Nuvriqo Portal+ for Jira Service Management Cloud.

## How Portal+ operates

Portal+ is built on Atlassian Forge. The first release uses Atlassian-hosted compute and Forge-hosted storage. Portal+ does not use a Nuvriqo-hosted remote backend, external database or third-party analytics service in V1.

## Data accessed

Portal+ accesses Jira Service Management information needed to provide its features, including customer-visible requests, request types, project/service-desk metadata, workflow statuses and customer organization metadata.

Customer request access is performed using the customer's Jira/JSM permissions where Portal+ is acting on behalf of the customer.

## Data stored

Portal+ stores configuration in Forge storage, including dashboard preferences, selected status IDs, selected organization IDs, category names/descriptions, mapped request type IDs/names, configuration version and update timestamp.

Portal+ V1 does not intentionally persist request descriptions, comments, attachments, customer passwords, Atlassian API tokens or Jira credentials in its configuration store.

## External data transfers

Portal+ V1 does not intentionally send Atlassian End User Data to external third-party services or Nuvriqo-hosted infrastructure. All app compute and persistent configuration storage are provided by Atlassian Forge.

## Data retention

Portal+ configuration is held in Atlassian Forge storage for the app installation. Applicable retention and deletion behavior after uninstall is governed by the Forge platform behavior in effect at that time.

## Security

Portal+ uses Forge authentication and declared Atlassian app scopes. The app does not request users' Atlassian passwords or personal API tokens.

## Changes to this policy

Nuvriqo may update this policy when Portal+ functionality or applicable requirements change. Material changes should be reflected on the published policy page and Marketplace listing.
